# System Analysis

## Introduction
System analysis is the process of studying a system to define its goals and improve efficiency.

## Objectives
- Understand SDLC phases
- Identify system components
- Design optimal system

## Non-Functional Requirements

### Availability
Runs 24/7 with minimal downtime.

### Reliability
Continuously monitored system.

### Scalability
Handles growth using MySQL.

### Accessibility
Easy login and access.

### Performance
Fast and smooth experience.

### Security
User authentication and data protection.

### Usability
User-friendly interface.

### Extensibility
Supports future features.
